Module Overview

An introduction to computer networking — covering data communication fundamentals, network types and topologies, the OSI model, IP addressing, HTTP and DNS, and core protocols like DHCP, ARP, and ICMP.

Day 1
Data Communication
Qualities, communication types & data types
▼

Day 1 covered the basics of data communication: its components, the qualities of a good communication system, and the different ways data can be transmitted.

Data Communication

Components: Sender, Medium, Receiver, Protocol.

Qualities of Data Communication
  • Delivery — data must be delivered to the correct sender and receiver.
  • Timeliness — data must be delivered on time.
  • Jitter — variation in the delay of packet delivery.
  • Accuracy — the data sent must be accurate / error-free.
  • Security
Types of Communication
  • Simplex — one-way communication (e.g. TV, Radio).
  • Half-Duplex — only one side can transmit at a time (e.g. walkie-talkie).
  • Full-Duplex — both sides can communicate freely at the same time (e.g. audio/video calls).
  • Transmission types: Parallel, Serial.
Data Transmission Types
  • Parallel — all bits transferred together.
  • Serial — bits transferred one at a time.
Types of Data
  • Oriented data — data that is directly given/provided.
  • Observed data — data collected automatically by observing behavior (e.g. how Instagram's algorithm observes user activity).
  • Inferred data — data predicted by analyzing observed data.
Day 2
Networking Roadmap
Network types, devices & topologies
▼

Day 2 mapped out the broader world of networking — types of networks, key terms, devices, and how computers can be physically connected.

Types of Networks
  • LAN — Local Area Network.
  • MAN — Metropolitan Area Network (data shared between people within a city).
  • WAN — Wide Area Network (data shared across a country/countries).
  • Internet — open-source, publicly accessible network.
  • Intranet — a private network limited to specific people (e.g. used by companies to prevent private data loss).
Key Concepts
  • Client-Server — the server acts as a bridge between the client (you) and the output/resource.
  • TCP — Transmission Control Protocol.
  • ISP — Internet Service Provider.
  • DNS — a system that resolves domain names to prevent naming/addressing conflicts.
  • NIC — Network Interface Card; connects a device to the LAN so data can be shared.
  • MAC ID — a unique, unchangeable hardware address (analogous to a mobile's IMEI number).
Networking Devices
  • Hub — a central connection point directly linked to other computers.
  • Switch — stores MAC addresses and saves them in frame format.
  • Router — transfers data in packet format and can send it to many devices; multiple users/devices connect together, with data sent via MAC address.
Topology (ways to connect computers)
  • Bus Topology — all devices connected via one main cable in series.
  • Star Topology — one central hub with devices connected in all directions from it.
  • Mesh — most efficient topology for data sharing.
  • Parent device, child device, grandchild device (hierarchy concept).
  • Ring — essentially a mix of two topologies.
Other Terms
  • IP Address, Routers, Server, Protocols.
  • Mail protocol: SMTP.
  • FTP, HTTPS, Interface.
  • Internet — secure, available to all.
Day 3
Topology, RAG Model & the OSI Model
Star/Mesh/Ring/Tree, RAG basics, 7-layer OSI model
▼

Day 3 continued with topology types, touched on the RAG model used with LLMs, and covered the OSI model in detail.

Topology (continued)
  • Star Topology — computers connected in a star formation.
  • Mesh Topology — all computers connected together; secure.
  • Ring Topology — loop connection; if one node has a problem, it can affect others.
  • Tree Topology
RAG Model
  • Works on top of LLMs; reduces hallucination.
  • Context-aware; uses memorization and testing.
  • Data is converted into vector/embedding form, then compared using similarity search — one of its best applications.
  • OCR note: for further learning, use the PaddleOCR repository.
OSI Model — 7 Layers

Open System Interconnection: a 7-layer model used for networking devices.

  • 1. Application — e.g. SMTP (mail), FTP, HTTPS; the interface layer where data transfer is visible to the user.
  • 2. Presentation — handles encryption, formatting, and compression; transforms data into bits.
  • 3. Session — establishes and maintains sessions; handles authorization and authentication; acts as a bridge.
  • 4. Transport — TCP (reliable, gets feedback/confirmation) vs UDP (no confirmation, no feedback); handles segmentation and error checking.
  • 5. Network — data is broken into small packets; handles IP addressing.
  • 6. Data Link — data is put into frames; links data to a physical (MAC) address; manages transfer speed between sender and receiver.
  • 7. Physical — physically transfers data as bits, via hardware like hubs and switches.
Additional Notes
  • ZIP files are used to compress the size of files/code.
  • Sender processes data top-to-bottom through the OSI layers; Receiver processes it bottom-to-top.
Day 4
IP Addressing, HTTP & URL Structure
IPv4/IPv6, HTTP methods, DNS, anatomy of a URL
▼

Day 4 covered data types, IP addressing, HTTP, DNS, and the full anatomy of a URL.

RAG Model, ZIP & OSI Direction

Works on top of LLMs; reduces hallucination; context-aware; uses memorization and testing; converts data into vector/embedding form, compared via similarity search. ZIP files used to compress file size/code. Sender processes top-to-bottom, Receiver processes bottom-to-top through OSI layers.

1. Types of Data
  • Oriented data — data that is directly given.
  • Observed data — automatically collected by observing behavior (e.g. Instagram's algorithm).
  • Inferred data — predicted by analyzing observed data.
2. IP Address

A unique address assigned to a device.

  • Public IP — accessible to all via the internet.
  • Private IP — available only to limited users, e.g. within private companies.
  • Static IP — an IP address that doesn't change.
  • Dynamic IP — changes when a device connects through a router (e.g. Raspberry Pi).
  • IPv4 — decimal format, 32-bit (e.g. 22.11.33.22), ~4.3 billion addresses.
  • IPv6 — hexadecimal format, 128-bit, created to overcome IPv4's address limit.
3. HTTP

HyperText Transfer Protocol — used to transfer data (HTML documents, images, multimedia) between web browsers and servers.

  • GET — fetch/retrieve data.
  • POST — create data.
  • PUT — update data.
  • DELETE — delete data.
4. DNS

Domain Name System. Since every website has a different IP address that's hard to remember, DNS maps a human-readable name to that IP (e.g. google.com → an IP address).

5. URL

Uniform Resource Locator — a web address that acts like a digital street address telling the browser where to go and how to retrieve content.

6. Scheme

The first part of a URL, telling the browser which protocol to use (http/https for web pages, mailto: for email clients, ftp: for file transfers).

7. Domain Name
  • Second-Level Domain (SLD) — the unique site/brand name (e.g. "google").
  • Top-Level Domain (TLD) — the extension (e.g. ".com", ".org") indicating entity type.
  • Subdomain — optional prefix (e.g. "www", "blog") to organize site sections.
8. Path

The specific location of a resource within the site's directory structure.

9. Query

Starts with ?; provides extra data like search terms or filters.

10. Fragment

The part after #; points to a specific section/anchor within a page.

Day 5
DHCP, ARP & ICMP
Automatic IP assignment & core network protocols
▼

Day 5 covered how devices automatically get IP addresses, how IPs map to hardware addresses, and how network errors get reported.

DHCP — Dynamic Host Configuration Protocol

Since IP assignment needs to be dynamic (able to change), DHCP is the protocol used. Works in 4 steps:

  • Discover — device discovers the server.
  • Offer — server offers an IP to the device.
  • Request — device requests that IP.
  • Acknowledge — server acknowledges and assigns the IP.
IP Address Concepts
  • Subnet Mask — divides an IP into two parts: network ID and host ID.
  • Default Gateway — the path a device uses to reach the internet.
  • Lease Time — the duration for which an IP address is assigned to a device.
ARP — Address Resolution Protocol

Maps known IP addresses to their corresponding physical MAC addresses, enabling communication within a local network.

ICMP — Internet Control Message Protocol

A network layer protocol used by routers and hosts to send error messages and operational information, such as diagnostics for latency and reachability.
