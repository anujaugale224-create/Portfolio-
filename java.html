Module Overview

An introduction to Java programming — starting with the basics of what a programming language is, moving through variables, operators, loops, methods, and arrays, and finishing with an introduction to classes, objects, and constructors.

Day 1
Introduction to Java
Programming basics, JDK/JVM, Hello World
▼

Day 1 covered the basics of programming languages and broke down the classic "Hello World" program line by line.

  • Learned the basics of programming languages, with a brief look at Python and C++.
  • Java is used for building apps; Python is commonly used for AI/ML. Java is primarily object-oriented (with some procedural elements), while languages like C are purely procedural.
  • Java tools: JDK and JVM — the JVM converts Java code into a language the computer understands.
Basic Code
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
  • public — an access modifier; means the class can be accessed from anywhere.
  • class — a blueprint containing variables and methods; every Java program is built from classes. The class name must match the filename (e.g. Demo.java → class Demo).
  • { } — opens and closes the "box": everything inside belongs to that class.
  • main() — the entry point; Java always starts running from here, like the front door of a house.
  • System.out.println() — System is the computer, out is the screen, println prints the given text and moves to the next line.
  • ; — marks the end of a statement.

Methods

A method is a block of code that performs a specific task.

static int add(int a, int b) {
    return a + b;
}

static void greet() {
    System.out.println("Hello");
}
public class Method {
    static void add(int a, int b) {
        System.out.println(a + b);
    }
    public static void main(String[] args) {
        add(5, 10); // Calling the static method
    }
}
public class Method {
    static void square(int a) {
        System.out.println(a * a);
    }
    public static void main(String[] args) {
        square(5); // Calling the static method
    }
}
Array
public class Array {
    public static void main(String[] args) {
        int[] arr = new int[3]; // array
        arr[0] = 4; // putting values
        arr[1] = 5;
        arr[2] = 7;

        System.out.println(arr[0]); // print on screen using System.out.println()
        System.out.println(arr[1]);
        System.out.println(arr[3]);
    }
}
Array with User Input
import java.util.Scanner;

public class Array {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); // Get input from user

        System.out.println("enter size");
        int size = sc.nextInt(); // Declaration of array

        int num[] = new int[size];
        // input
        for (int i = 0; i < size; i++) { // for getting input
            num[i] = sc.nextInt();
        }

        System.out.println("array is");
        for (int i = 0; i < size; i++) { // for printing array values
            System.out.println(num[i]);
        }
    }
}
2D Array
import java.util.Scanner;

public class Array {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); // Get input from user

        int row = sc.nextInt();
        int col = sc.nextInt();

        int num[][] = new int[row][col];
        // input
        for (int i = 0; i < row; i++) {
            for (int j = 0; j < col; j++) {
                num[i][j] = sc.nextInt();
            }
        }

        for (int i = 0; i < row; i++) {
            for (int j = 0; j < col; j++) {
                System.out.println(num[i][j]);
            }
            System.out.println();
        }
    }
}
Day 6
Classes, Objects & Constructors
Defining classes, creating objects, constructor chaining
▼

Day 6 introduced classes and objects, and how constructors are used to initialize them.

Class with Constructor & Method
class Student {
    String name;
    int age;
    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
    void display() {
        System.out.println(this.name);
        System.out.println(this.age);
    }
}
Class with main() & Object Creation
public class Student {
    int age;
    String name;

    Student(int age, String name) {
        this.age = age;
        this.name = name;
    }

    void display() {
        System.out.println(this.age + " " + this.name);
    }

    public static void main(String[] args) {
        Student s1 = new Student(20, "Ajay");
        s1.display();
    }
}
Constructor Chaining
public class CallConstructor {
    CallConstructor() {
        System.out.println("Ajay");
    }
    CallConstructor(int a) {
        this();
        System.out.println(a);
    }
    public static void main(String[] args) {
        CallConstructor constructor = new CallConstructor(100);
    }
}
📝

Key Learning: A constructor can call another constructor in the same class using this(), allowing constructors to be chained together.
